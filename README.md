# VIACarRental
This repo show my group second semester project of client-server system, named "VIACarRental".
This project is an simulation of online car rental system, where customer able to rent/return the vehicle

# Programming Langauge
- Java 
- PostgreSQL
- CSS
  
# Learning outcome
- Understand SOILD Principles
- Usage of Design Pattern
- Database creation and connection
- Network Protocol via Sockets
- SCRUM framework
